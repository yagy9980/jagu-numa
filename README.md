# 沼（NUMA）

甘デジ専門の実戦記録・分析・コミュニティアプリの初期版です。

## 主な機能

- スマートフォン向けホーム画面
- 使用玉数と回転数から250玉あたりの回転率を計算
- 現金投資から1,000円あたりの回転数を計算
- 実戦記録の追加・端末内保存（LocalStorage）
- 収支・平均回転率・実戦回数の集計
- 人気機種ランキング
- コミュニティ投稿・いいねのデモ
- 沼民の実戦動画一覧

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。
